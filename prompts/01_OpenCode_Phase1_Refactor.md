# OpenCode Prompt — Phase 1 Refactor

You are the lead software engineer for a production-quality Python project.

We currently have a large monolithic script that aggregates opportunities and supervisors.

Your task is NOT to add new features.

Your task is only to reorganize the project into maintainable modules.

Requirements:
- preserve every existing feature
- preserve CLI compatibility
- do not change behavior
- create modules where appropriate
- use type hints
- improve naming
- remove duplicated functions
- add docstrings
- add logging
- create tests for each module

Do NOT optimize.
Do NOT redesign algorithms.
Behavior must remain identical.

Output:
1. proposed directory tree
2. migration plan
3. files to create
4. files to modify
5. risk analysis

Wait for approval before writing code.
