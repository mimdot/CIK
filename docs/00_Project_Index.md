# Project Index

## What this project is
A career intelligence platform that reads a user's background, understands their research or professional profile, and recommends the best-fit opportunities and supervisors.

## Current state
- Existing scripts already support multi-major PhD aggregation, OpenAlex-based supervisor discovery, strict PhD-only filtering, country handling, and HTML dashboard output.
- The first release should reuse the current script base rather than replace it.

## What an agent should do next
1. Read the PRD.
2. Read the architecture.
3. Read the roadmap.
4. Read the prompt files.
5. Implement Phase 1 only.
6. Keep the ranking deterministic.
7. Use the LLM only for extraction, explanations, and email drafting.

## One-sentence goal
Find the best position or supervisor for a user based on accurate, structured understanding of their skills and goals.
